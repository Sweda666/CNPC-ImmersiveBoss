# 自定义 Boss 血条

## 显示模式

本模组在 CustomNPCs 的 Bossbar 设置中增加两种模式：

| 模式 | 行为 |
| --- | --- |
| `3` 显示自定义血条 | 常显，距离玩家超过 `128` 格时不渲染 |
| `4` 战斗时显示自定义血条 | 有目标、受伤或攻击时显示，约 `100 tick` 无战斗活动后隐藏 |

客户端屏幕顶部最多同时渲染 3 条自定义血条。战斗模式仍要求对应 NPC 实体已加载到客户端。

## PNG 素材

一条血条使用一张垂直分为两半的 PNG：上半是边框、背景与装饰，下半是生命填充层。两半必须等宽、等高并准确重合；下半会按生命百分比从左向右裁切并乘以所选 RGB 颜色，建议使用白色或灰度填充。

```text
+------------------------------+
| 上半：边框、背景、固定装饰   |
+------------------------------+
| 下半：可着色的生命填充层     |
+------------------------------+
```

资源包示例：

```text
assets/mypack/textures/gui/bossbar.png
```

GUI 中填写 `mypack:textures/gui/bossbar.png`，不要填写磁盘路径或 `assets/` 前缀。

## GUI 配置

1. 打开 NPC 的显示设置。
2. 选择“显示自定义血条”或“战斗时显示自定义血条”。
3. 点击“编辑”，手动填写纹理路径，或通过“选择”浏览资源管理器中的 PNG。
4. 设置颜色、X 偏移、X/Y 缩放以及纹理宽高，保存设置。

| 参数 | 默认值 | 用途 |
| --- | ---: | --- |
| 颜色 | `FFFFFF` | 六位 RGB，不带 `#` |
| X 偏移 | `0` | 保护左右固定端帽，不参与生命裁切 |
| X/Y 缩放 | `0.5` | 控制屏幕显示尺寸，必须大于 0 |
| 宽度/高度 | `516` / `95` | PNG 基准尺寸，必须大于 0 |

实际显示宽度为 `宽度 * X缩放`，单条血条高度为 `高度 * Y缩放 / 2`。普通矩形填充保持 X 偏移为 `0`；带固定端帽的素材再按透明边缘宽度调整。

## 排查

- 模式必须是 3 或 4，且纹理路径不能为空。
- 模式 4 只在战斗计时有效时显示。
- 确认 PNG 上下层严格对齐，总高度最好为偶数。
- 颜色填写 `FF4040`，不要带 `#`。
- 资源修改后按 `F3+T` 重载。
